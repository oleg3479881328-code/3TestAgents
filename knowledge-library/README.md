# Knowledge Library

## Purpose

The Knowledge Library stores reusable patterns, rules, architectural lessons, workflow decisions, and research findings extracted from workflow runs.

A knowledge-library entry is not automatically a skill.

## Difference Between Skill and Knowledge Entry

### Skill

A skill is an executable workflow instruction.

Example:
`skills/research/github-repository-research/SKILL.md`

### Knowledge Entry

A knowledge entry is a reusable idea, rule, pattern, decision, or lesson.

Example:
`knowledge-library/patterns/document-first-mvp.md`

## Rules

Every knowledge entry must include:
- purpose;
- context;
- reusable pattern;
- when to use;
- when not to use;
- source workflow or reference;
- status.

## Initial Categories

```text
knowledge-library/
  README.md
  patterns/
  decisions/
  anti-patterns/
  workflow-lessons/
```

## MVP Decision

The Knowledge Library is Markdown-first.

It exists to prevent useful architectural thinking from being lost inside temporary chats or isolated workflow files.
